GCSE Computer Science: Python Programming Fundamentals

Variables and Data Types
A variable is a named storage location in memory. In Python, you do not declare a type — the interpreter infers it.

    name = "Alice"      # string (str)
    age = 16            # integer (int)
    score = 95.5        # float
    passed = True       # boolean (bool)

Casting converts between types: int("42") gives the integer 42. str(16) gives the string "16".

Selection (if/elif/else)
Selection lets a program make decisions.

    grade = int(input("Enter your grade: "))
    if grade >= 70:
        print("Distinction")
    elif grade >= 55:
        print("Merit")
    else:
        print("Pass")

The condition after if must evaluate to True or False. Indentation (4 spaces) marks the block that belongs to each branch.

Iteration (loops)
A for loop repeats a known number of times. A while loop repeats until a condition is false.

    # for loop — count 1 to 5
    for i in range(1, 6):
        print(i)

    # while loop — keep asking until valid input
    number = 0
    while number < 1 or number > 10:
        number = int(input("Enter a number between 1 and 10: "))

Subroutines (functions and procedures)
A function returns a value. A procedure (a function with no return) performs an action.

    def area_of_rectangle(width, height):
        return width * height

    def greet(name):
        print("Hello,", name)

Parameters are the variable names in the definition. Arguments are the actual values passed in the call.

Lists and Arrays
A list stores an ordered collection of items. Items are accessed by index, starting at 0.

    fruits = ["apple", "banana", "cherry"]
    print(fruits[0])     # apple
    fruits.append("date")
    fruits.remove("banana")
    print(len(fruits))   # 3

A 2D list is a list of lists, used to represent a grid or table.

    grid = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
    print(grid[1][2])    # 6  (row 1, column 2)

String Handling
Strings support indexing and slicing, just like lists.

    word = "Computer"
    print(word[0])       # C
    print(word[3:7])     # put
    print(len(word))     # 8
    print(word.upper())  # COMPUTER
    print(word.lower())  # computer

File Handling
Programs can read from and write to text files.

    # Writing
    with open("scores.txt", "w") as f:
        f.write("Alice: 95\n")
        f.write("Bob: 87\n")

    # Reading line by line
    with open("scores.txt", "r") as f:
        for line in f:
            print(line.strip())

Using with ensures the file is closed automatically, even if an error occurs.

Exception Handling
A try/except block catches runtime errors so the program does not crash.

    try:
        number = int(input("Enter a number: "))
        result = 100 / number
        print(result)
    except ValueError:
        print("That was not a valid number.")
    except ZeroDivisionError:
        print("Cannot divide by zero.")

Algorithms: Searching
Linear search checks every element one by one. Time complexity: O(n).
Binary search repeatedly halves a sorted list. Time complexity: O(log n). The list must be sorted first.

Algorithms: Sorting
Bubble sort compares adjacent pairs and swaps if out of order, repeating until no swaps occur.
Merge sort splits the list in half recursively, sorts each half, then merges. More efficient for large lists.

Pseudocode and Flowcharts
GCSE exams use OCR pseudocode conventions. Key constructs:
    x = 5
    IF x > 3 THEN ... ENDIF
    FOR i = 0 TO 9 ... NEXT i
    WHILE condition DO ... ENDWHILE
    FUNCTION name(param) ... RETURN value ENDFUNCTION
